# ADR-001: Implementação de cache para consultas ao cardápio

* **Status:** Aceito
* **Data:** 17/11/2026
* **Decisores:** Sofia, Eduarda, Caio, Kawai

## Contexto
Imagina-se que serão feitas múltiplas consultas ao cardápio do restaurante universitário, tanto para realizar um pedido quanto para fazer uma alteração. Assumimos que os registros que representam o cardápio não variam muito (o que é uma premissa razoável), o que motiva fortemente a decisão.

## Decisão
Implementação de memória cache para consultas ao cardápio do restaurante universitário.

## Consequências

* **Positivas (Prós):** Diminuição no tempo de resposta das consultas e alívio de carga de trabalho no servidor.
* **Negativas / Riscos (Contras):** Complexidade de implementação, necessidade de políticas de invalidação e possível consistência eventual.
* **Mitigações:** Uma equipe com mais integrantes poderia mitigar os efeitos negativos gerados pela complexidade e a necessidade da existência de políticas de invalidação de cache; A consistência eventual é característica da cache, mas como estamos seguindo a premissa de que os itens do cardápio não variam muito, então podemos assumir de forma segura que raramente teremos problemas com isso.
