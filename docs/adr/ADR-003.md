# ADR-003: Implementação de Arquitetura Hexagonal

* **Status:** Rejeitado
* **Data:** 17/11/2026
* **Decisores:** Sofia, Eduarda, Caio, Kawai

## Contexto
Durante o projeto inicial, a equipe avaliou a possibilidade da implementação de uma Arquitetura Hexagonal no sistema, com a motivação de isolar as regras de negócio e facilitar a manutenibilidade das portas e adaptadores para comunicação entre os clientes e o sistema. 
Numa segunda análise, a equipe notou que o escopo do projeto não era grande o suficiente, não haviam muitos membros para o trabalho e a implementação da arquitetura não traria um retorno satisfatório com base em sua complexidade.

## Decisão
A equipe optou por adotar uma arquitetura **Cliente-Servidor** que cumpria melhor os requisitos de escopo e complexidade.

## Consequências

* **Positivas (Prós):** Diminuição da complexidade do código, facilitando implementação e depuração posterior. 
* **Negativas / Riscos (Contras):** As regras de negócio ficam mais acopladas ao restante do sistema.
* **Mitigações:** Organização limpa do código para modularização de cada parte do sistema.
